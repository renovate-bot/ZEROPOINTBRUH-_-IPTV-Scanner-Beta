Unchecked / dead directory

Separate from the live catalog. These channels are unchecked (pending/unknown) or dead (offline/error) and may not load. If one plays, report it so we prioritize a health check.

{{ base_url }}/unchecked/ {{ base_url }}/unchecked/all.json {{ base_url }}/unchecked/streams.json {{ base_url }}/unchecked/dead.json {{ base_url }}/api/v1/unchecked?page=1&kind=all

On success: POST /api/report-alive with {"url":"<stream url>"}

Unchecked directory (warning)

Channels under /unchecked/ may fail to play. Treat them as experimental. When a stream does load, call POST /api/report-alive — we promote it to the live list and put it on the priority health-check queue.

  • /unchecked/all.json — pending + unknown + offline + error
  • /unchecked/streams.json — unchecked only (pending / unknown)
  • /unchecked/dead.json — dead only (offline / error)
  • Same {{ page_size }}/page + rate limit as live (~{{ wait_seconds }}s, HTTP 429 if rushed) — e.g. /unchecked/dead2.json

Quick start (any client)

  1. GET {{ base_url }}/streams.json → page 1 (≤{{ page_size }} items)
  2. Use that page’s streams array only
  3. If has_more, GET next_url after {{ wait_seconds }}s
  4. Or use M3U: /streams.m3u → /streams2.m3u
